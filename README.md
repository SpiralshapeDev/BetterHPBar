# Better HP Bar

[Apache License, Version 2.0]: https://github.com/SpiralShapeDev/BetterHPBar/blob/master/LICENSE-APACHE
[Bepinex pack for Undermine]: https://www.nexusmods.com/undermine/mods/5

This mod makes it so that the HP Bar that shows your max health with your current HP.
By default, it also shows the max health of bosses, this can be disabled in the mod's BepInEx configuration.
When displaying health, there are two modes, "HP / MAX_HP" & "HP%". You can choose which of these two display modes you want in the mod's BepInEx configuration. By default, the first option is activated.

### Requirements
- [Bepinex pack for Undermine]

## Installing
1. Install [BepInEx][Bepinex pack for Undermine]
2. Download and extract this mod.
3. Copy the .dll mod file to your "<Undermine-Steam-Files>/BepInEx/plugins" directory.
4. Run the game.  Enjoy!

## Usage
Modify the entries automatically generated in your BepInEx configuration file path, usually located at [ ./BepInEx/config/SpiralMods.BetterHPBar.cfg ].
If you cannot see this file, try running the game with the mod so that the file can be generated by BepInEx, if that doesn't work, verify if you have the mod correctly installed.

## Building
1. Copy files from `<Undermine-Steam-Files>/BepInEx/core` to `.libs`
   1. `0Harmony.dll`
   2. `BepInEx.dll`
   3. `BepInEx.Harmony.dll`


2. Copy files from `<Undermine-Steam-Files>/UnderMine_Data/Managed` to `.libs`
   1. `UnderMine.dll`
   2. `UnityEngine.dll`
   3. `UnityEngine.CoreModule.dll`
   4. `UnityEngine.UI.dll`
   5. `UnityEngine.UIModule.dll`
   6. `UnityEngine.TextRenderingModule.dll`
   7. `Unity.TextMeshPro.dll`
   8. `Rewired_Core.dll`


3. Build solution


4. Built mod should be located at `bin/Debug/BetterHPBar.dll`
